山门一盏灯 · 单人离线版

电脑游玩
把压缩包完整解压到固定文件夹，在 Chrome 或 Edge 中打开 index.html。图像、功法、剧情均随包附带，无须外部下载。移动文件夹、换浏览器或清除网页数据前，请在游戏右上角的设置导出迁移档。

手机游玩
使用已发布的网址，在 Safari 中选择“分享 → 添加到主屏幕”。第一次联网打开并完成缓存后可离线使用。在线版、电脑本地版、不同设备各有自己的存档，换设备可用设置中的导出、导入接续进度。

GitHub Pages
本包的 index.html 与 assets、各 JS 和 CSS 位于同一层，把解压后的文件上传到仓库发布目录即可，无需构建。仓库的 Settings → Pages 中选择发布分支及根目录即可部署。普通个人 Pages 页面通常公开，人物存档保存在游玩的设备上。

开局
任选八签中的五项留签，每角最多五次抽取，主灵根至多一种。完成正传、探索地方旧事或秘境可获经验和灵石。关闭前可在修行安排闭关。没钱时可做坊间差事或售出闲置材料。进入死斗后，归零即永久结束整条世界线。道祖立传后可主动转世。
